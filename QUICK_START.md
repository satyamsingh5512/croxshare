# ⚡ Quick Start Guide - Nebay Share

## 🚀 **Run the App**

```bash
# 1. Start development server
npm run dev

# 2. Open in browser
http://localhost:3002/nebay-pro
```

**That's it!** The app is now running with all premium features enabled.

---

## 🎯 **Try These Features**

### **1. Basic File Transfer (30 seconds)**

**Device 1 (Sender):**
1. Open http://localhost:3002/nebay-pro
2. Click **"Generate Code"** button
3. See 6-digit code (e.g., `ABC123`)

**Device 2 (Receiver):**
1. Open http://localhost:3002/nebay-pro  
2. Enter code: `ABC123`
3. Click **"Connect"**

**Transfer:**
1. Drag file onto sender's page
2. Click **"Send X files"**
3. File appears on receiver instantly!

---

### **2. Advanced Features**

#### **🗜️ File Compression**
- Drag a text file (JSON, HTML, etc.)
- Watch toast: "Compressing..."
- See: "73.2% smaller - Sending..."
- Transfer completes MUCH faster!

**Best for:** Code files, documents, logs (60-85% savings)

---

#### **📋 Clipboard Paste**
- Copy a file in file manager
- Press **Ctrl+V** (or Cmd+V)
- File appears in queue!

**Also works with screenshots and copied images**

---

#### **⏸️ Pause/Resume**
- Send a large file
- Click **"Pause"** button
- Click **"Resume"** to continue
- Transfer picks up where it left off!

---

#### **🔔 System Notifications**
- Click 🔔 Bell icon in header
- Grant notification permission
- Hear sound effects! 🎵
- See OS notification popups

---

#### **📊 Statistics Dashboard**
- Click 📊 BarChart icon
- View comprehensive analytics
- Track success rate, data volume, speed

---

#### **⌨️ Keyboard Shortcuts**
```
Esc           - Close any modal
Ctrl+H        - Open transfer history
Ctrl+S        - Send selected files
Ctrl+V        - Paste files from clipboard
Space         - Pause/Resume transfer
Shift+?       - Show shortcuts help
```

## 🎓 **Pro Tips**

### **💡 Compress Smart**
```
✅ DO compress: .txt, .json, .html, .css, .js
❌ DON'T: .jpg, .mp4, .zip (already compressed)
```
**The app does this automatically!**

### **💡 Paste Screenshots**
```
Windows: Win+Shift+S → Ctrl+V
Mac: Cmd+Shift+4 → Cmd+V
```

### **💡 Batch Transfer**
```
Drag all 10 files at once
Click "Send 10 files"
All transfer together!
```

## 🔧 **Troubleshooting**

**Connection Failed?**
- Check both devices on same network
- Disable VPN temporarily
- Try different code

**Slow Transfer?**
- Enable compression (automatic for text)
- Close other network apps
- Move closer to WiFi router

**No Notifications?**
- Click 🔔 icon to enable
- Check browser settings
- Allow notification permission
